# Rongyang Ye — Personal Portfolio

Clean portfolio with selected work, biography, portrait, résumé, and contact links.

Live at https://snorlaxpapa.github.io/.

The website is in `site/`. Edit `index.html`, `styles.css`, or `script.js`, then push to `main`; the GitHub Pages workflow publishes that directory automatically. No build or package installation is required.

To preview locally, run `python3 -m http.server 4174 --directory site` and open http://localhost:4174/.
